# 概念笔记

按主题编号，一个概念一篇。笔记不是摘抄，而是你自己的心智模型。

## 命名

`01-wallets-and-signatures.md`、`02-transactions-and-gas.md`、`03-rpc-and-blocks.md` …

## 模板

```markdown
# 主题

## 一句话解释
## 我的心智模型
## 为什么需要它
## 实验（代码/命令/结果）
## 容易错的地方
## 和本项目的关系
## 面试式自问自答（3~5 个）
## 英文摘要（3~5 句）
```

## 判断写清楚的标准

- 不看资料，能画出数据流。
- 能用一个反例说明它为什么必要。
- 能指出项目里具体哪一行代码用到了它。
- 能回答「如果换成另一种方案会怎样」。
