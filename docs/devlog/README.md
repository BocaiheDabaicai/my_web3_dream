# Devlog

每个检查点或一个有意义的小里程碑写一篇，中英双语。对外发布时删掉隐私信息与未公开的公司内容。

## 命名

`0001-environment-spike.md`、`0002-first-chain-read.md` …

## 模板

```markdown
# <里程碑标题>

## 中文
### 做了什么
### 学到了什么（机制，而不是步骤）
### 卡在哪里 / 怎么解决
### 下一步

## English
### What I built
### What I learned
### What broke
### Next
```

## 发布原则

- 先讲问题和取舍，再讲用了什么库。
- 附一张架构图或截图；不贴密钥、不贴私人数据。
- 英文版本控制在 300 词左右，适合 X thread 或博客摘要。
- 每个阶段至少一篇，持续比数量重要。
