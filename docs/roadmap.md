# 学习与构建路线

进度由检查点驱动，不设日期与小时数。完成并通过验收后进入下一关。

## 每个检查点的统一交付

1. **可运行代码**：能在本地启动，能演示，新增关键路径有测试。
2. **自动化测试**：优先使用录制 fixture；单元测试不依赖外网。
3. **中文笔记**：概念、心智模型、实验中遇到的坑、面试式解释。
4. **英文 devlog 摘要**：作为 X / 博客素材，同时练习技术写作。
5. **口头复述**：用 15 分钟把这一关讲给一个面试官听。
6. **追问与破坏任务**：回答 3~5 个机制问题，并修复一个被故意注入的缺陷。

## 协作方式

- **我**：给任务书、讲原理、搭脚手架与工具链、定验收标准、Code Review、出追问和破坏任务。
- **你**：写核心逻辑（RPC 层、ABI、工具定义、Agent 循环、界面），写笔记并完成复述。
- 想独立完成某一关时直接说，我只做审查与追问。
